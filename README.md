# 华中农业大学本科教材数据集（HZAU 教材清单 + 高清封面）

> 以 **华中农业大学 2025 版本科人才培养方案** 与各学院教学大纲为基准整理的教材清单，覆盖：
> **动物医学（五年制，大一~大五）**、**动物科学（四年制）**、以及全校公共课（思政、高数、大学物理、化学、英语等）。
> 只收录**最新版**教材，淘汰过时旧版。

## 📌 全量教材覆盖说明（重要，如实告知）
- 华农现有 **71 个本科专业**（见 `专业目录.csv`），动物医学与兽医公共卫生为**五年制**，其余**四年制**。
- 全校教材累计约上千本。已完整覆盖：**动物医学（五年制 大一~大五）+ 动物科学 + 全校公共课**（52 条，含已核验 ISBN）。
- 其余专业（水产、植科、生科、资环、工科、经管、文法、信息等）**尚未逐专业展开**，原因：
  1. **华农本科生院《2025版人才培养方案》PDF 下载需输入验证码**，程序无法自动抓取课程清单；课程名需你下载 PDF 提供，或我逐学院人工核验。
  2. 教材名+ISBN+封面必须**逐门从教学大纲/出版社核验**，华农无全校教材总表，一次性"填满"必然出错，故不编造。
- 扩展方法：按 `metadata.csv` 相同格式，一个学院一个学院补（我已在做动医，可直接续做水产、植科、生科等）。

## 📄 metadata.csv 字段说明
| 字段 | 含义 |
|---|---|
| 专业 | 适用专业（动物医学/动物科学/公共课） |
| 学制 | 5年（动医）/ 4年（动科等） |
| 学年 / 学期 | 大一~大五 + 学期 |
| 课程名称 | 华农实际开课课程 |
| 课程性质 | 必修 / 专业基础 / 专业方向选修 / 通识选修 / 思政 |
| 教材名称 | 指定/推荐教材（最新版） |
| 主编 / 版次 / 出版社 / 出版年 | 教材元信息 |
| ISBN | 已核验的直接填写；其余由脚本按书名自动补全 |
| 数据状态 | 已核验 / 待脚本补全 / 无正式教材 |
| 数据来源 | 高教社官网 / 教学大纲 / 培养方案 / 马工程教材 等 |

## 🚀 使用步骤（在你自己电脑上跑一次即可拿到全部封面）
```powershell
cd C:\Users\yzs\Desktop\HZAU-教材数据集-GitHub
pip install -r requirements.txt     # 安装依赖（只需一次）
python scripts\fetch_covers.py       # 自动下载全部高清封面到 covers\，并回填ISBN
```
> 脚本会：① 对未填 ISBN 的教材按书名从当当检索补全；② 按 ISBN 抓取当当高清封面；
> ③ 封面保存为 `covers/ISBN_书名.jpg`；④ 把补全的 ISBN 写回 `metadata.csv`。

## 📤 上传到 GitHub
1. 本地建仓：`git init` → `git add .` → `git commit -m "HZAU本科教材数据集"`
2. 在 GitHub 新建空仓库（如 `hzau-textbooks`），复制远程地址
3. `git remote add origin <你的仓库地址>` → `git push -u origin main`
4. 建议在仓库首页放一张封面预览（把 `covers` 里几张图拼成一张 README 头图）

## ⚠️ 说明与边界
- 本数据集**以动物医学（五年制）为完整核心**，动物科学与公共课为配套；其他专业（水产、植科、生科、经管等）尚未逐学院展开，可按 `metadata.csv` 相同格式自行扩展。
- 封面图片来自当当商品页原图（320px，当当可提供的最高画质），仅供学习整理使用，版权归出版社所有。
- 部分通识/选修课无固定教材（只有讲义），已标注「无正式教材」。
- 「数据状态=待脚本补全」的 ISBN 由脚本自动回填；少数图书当当无货时会标记未找到，可人工补图。
