# 华中农业大学本科教材数据集

> 为校园经济打样：收二手书的兄弟可以参照这个摸清全校专业教材行情；做 AI Agent 的可以直接复刻这套流程去爬自己学校，省 token。

基于华中农业大学 **2025 版人才培养方案**，整理全部本科专业、全部年级的课程教材信息，含**高清封面图**与 **ISBN**。

## 项目定位

### 给校园经济从业者
- 收二手书前，先查这个表知道每个专业每学期用什么书、哪个版次，避免收错版本砸手里
- 按学院→专业→年级筛选，快速定位某栋宿舍楼/某个学院的教材需求量
- ISBN 直接对当当/孔夫子/多抓鱼查回收价

### 给 AI Agent 开发者
- 本项目完整开源了从「培养方案 PDF → 课程总表 → 教材匹配 → 豆瓣补 ISBN+封面」的全流程脚本
- 别的学校的同学可以 fork 后替换 PDF，跑 `scripts/` 下的脚本即可复刻，不用从零写 prompt 烧 token
- 核心脚本不到 200 行，逻辑透明可审计

## 数据来源

1. **课程清单**：华中农业大学各学院 2025 版人才培养方案 PDF（共 15 份）
2. **教材匹配**：全国高等农林院校统编教材 + 各学科经典教材，取最新版次
3. **ISBN 与封面**：豆瓣读书（`book.douban.com`）搜索接口 + 详情页提取，封面为豆瓣大图（`/l/public/`）

## 使用方法

### 查看数据
直接用 Excel / 飞书表格打开 `课程教材总表.csv`，按学院、专业、学期筛选即可。

### 重新生成封面与 ISBN
```bash
pip install -r requirements.txt
python scripts/fetch_master.py
```
脚本会遍历 `课程教材总表.csv` 中已配教材，通过豆瓣搜索补全 ISBN 并下载高清封面到 `covers/`。

### 生成可视化展示页
```bash
python scripts/build_showcase.py
```
生成 `showcase.html`，内含全部封面画廊与各学院覆盖率统计。

### 复刻到其他学校
1. 替换 `_pdf文本/` 下的培养方案 PDF（用 `scripts/parse_curriculum.py` 重新解析）
2. 修改 `scripts/college_*.py` 中的教材映射表
3. 跑 `scripts/fetch_master.py` 补 ISBN+封面

## 说明与边界

- 培养方案 PDF 中第 8 学期的「专业选修课程目录」表含大量课程代码与英文混排行，已在解析时过滤，不参与教材匹配。
- 实验课、实习、社会实践、毕业论文等环节无固定理论教材，未匹配。
- 通识选修课无统一指定教材，未匹配。
- 仅 6 本冷门教材豆瓣未收录（缺 ISBN+封面）：物理化学（第6版）、种子检验原理与技术、农业资源与环境概论、水产药物学、观赏鱼类养殖学、名特水产养殖学，需手动补充。
- 封面图片版权归各出版社所有，本数据集仅供学习整理参考。
